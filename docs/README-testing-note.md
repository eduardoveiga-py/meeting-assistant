# Nota sobre experimentos anteriores

As branches de prova de conceito de captura de monitor e `HallOutputWindow` são experimentais e não fazem parte da arquitetura principal atual.

O fluxo principal usa a saída secundária nativa do JW Library. Não reintroduzir captura de fonte OBS inativa, captura de monitor inteiro ou uma janela própria sobre a saída do JWL sem uma necessidade arquitetural nova e uma prova técnica isolada.
