# Meeting Assistant 0.7.0 — Windows 11 x64

Primeira release candidata com instalador do aplicativo e da câmera nativa.
Python, bibliotecas e DLLs da câmera estão incluídos. Não é necessário instalar
Python, compilar ou usar Git para executar esta distribuição.

## Novidades e correções

- Câmera virtual Media Foundation própria para WhatsApp, recebendo o Program do OBS.
- Botão da câmera na tela principal e inicialização automática após conectar ao OBS.
- Prévia NV12 contínua com transporte independente da câmera e descarte de quadros atrasados.
- Barramento de áudio da mesa e mídias para Zoom e WhatsApp via VB-CABLE.
- Controle individual do retorno do WhatsApp, silenciado por padrão.
- Botão Texto do Ano; captura, atualização e aplicação da foto no OBS.
- Assistente de configuração, cenas padronizadas, WebSocket e câmera IP.
- Python 3.12 x64 verificado, ambiente incompatível preservado em backup,
  dependência pycaw corrigida e download separado das DLLs no modo Python.
- Atualizações do provedor nativo usam DLL versionada, evitando sobrescrever arquivo em uso.
- Comportamento validado das duas telas e da troca JWL/Zoom preservado.

## Instalar ou atualizar

1. Use Windows 11 x64, build 22000 ou superior.
2. Feche Meeting Assistant, OBS, WhatsApp e a sessão da câmera virtual.
3. Baixe **MeetingAssistant-Setup-0.7.0.exe** e execute. Aceite a permissão do Windows.
4. Mantenha câmera e ponte selecionadas; indique a pasta do OBS. Se não tiver OBS,
   desmarque a ponte, instale o aplicativo e use o assistente para instalar OBS e
   depois instalar a câmera/ponte nativas.
5. Abra o aplicativo pelo atalho. O assistente solicita os ajustes desta versão.
6. No Zoom/WhatsApp selecione CABLE Output como microfone. Para vídeo, use OBS Virtual
   Camera no Zoom e Meeting Assistant no WhatsApp.

OBS, Zoom, JW Library, WhatsApp e VB-CABLE são componentes externos. OBS/Zoom podem
ser instalados pelo assistente via WinGet. JW Library/WhatsApp e o driver VB-CABLE
exigem instalação pelos respectivos distribuidores. Configurações e fotos locais
são preservadas: o instalador não inclui senhas, links de reunião ou telemetria.
Microsoft Visual C++ x64 é incluído com assinatura verificada na compilação.

O ZIP portátil contém executável, Python, bibliotecas e pacote nativo; extraia tudo
antes de abrir MeetingAssistant.exe. Em máquina nova, prefira o instalador para registrar
a câmera e instalar a ponte. O desenvolvimento por git pull + scripts/run.ps1 continua
disponível e independente do executável.

## Limitações e recuperação

- Executáveis próprios ainda não têm assinatura Authenticode; Windows pode mostrar o
  editor como desconhecido. Confira origem GitHub e SHA256 publicado.
- Atualizador dentro do app e tutorial ilustrado completo continuam pendentes.
- Uso simultâneo OBS/JWL/Zoom/WhatsApp exige CPU suficiente; sobrecarga pode causar
  travamentos. Câmera virtual transporta vídeo; áudio usa VB-CABLE.
- Desinstalação remove o app, preservando dados locais e componentes nativos compartilhados
  com o modo Python. Para remover câmera/ponte, use RemoveCamera/RemoveBridge no script
  nativo com os aplicativos fechados.
- Para retornar ao modo Python, use sua pasta Git e scripts/run.ps1. Faça backup dos
  ajustes/fotos antes de testar outra versão; não use reset --hard para atualizar.
